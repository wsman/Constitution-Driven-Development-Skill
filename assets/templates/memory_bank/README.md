# Memory Bank

This directory separates current governance from historical evidence:

- `t0_core`: authority and current state;
- `t1_axioms`: explanatory context;
- `module_support_map.yaml`: coverage and routing contract;
- `t2_standards`: reusable `DS-*.md` constraints;
- `t2_protocols`: executable `WF-*.md` workflows;
- `t3_archives`: module-owned historical evidence.

T3 is non-authoritative and cannot silently amend current truth.
